To comply with privacy regulations, you can prevent 3rd party iframes from loading before gaining user consent. Enable this feature in the CookieChimp dashboard, then update your website's embeds.

## How do I block an iframe?

```html
<div data-service="YouTube" data-id="<video-id>"></div>
```

<Note>
  The `data-service` attribute must match exactly how the service is named in [vendor management](vendor-management#what-are-vendors).
</Note>

## How do I customize the iframe placeholder?

```html
<div
  data-service="YouTube"
  data-id="5b35haQV7tU"
  data-autoscale
  data-iframe-id="YouTubeEmbed"
  data-iframe-loading="lazy"
  data-iframe-frameborder="0"
></div>
```

### What configuration options are available?

- `data-service`: [String, Required] Service name (e.g., YouTube, Vimeo, Google Maps).
- `data-id`: [String, Required] Unique resource ID (e.g., video ID).
- `data-title`: [String] Notice title.
- `data-params`: [String] Iframe query parameters.
- `data-thumbnail`: [String] Path to custom thumbnail.
- `data-ratio`: [String] Custom aspect ratio (e.g., "16:9").
- `data-autoscale`: Responsive iframe that fills parent width and scales proportionally.
- `data-widget`: Use for custom widgets with explicit width and height.


## Supported Services

Each service expects a different `data-id` format. Use `data-autoscale` for video embeds, and `data-widget` with an explicit width and height for audio widgets.

#### YouTube

`data-id` is the video ID from the YouTube URL (for example, `tgbNymZ7vqY` from `youtube.com/watch?v=tgbNymZ7vqY`).

```html
<div data-service="YouTube" data-id="tgbNymZ7vqY" data-autoscale></div>
```

#### Vimeo

`data-id` is the numeric video ID from the Vimeo URL (for example, `1060110670` from `vimeo.com/1060110670`).

```html
<div data-service="Vimeo" data-id="1060110670" data-autoscale></div>
```

#### Spotify

`data-id` is the resource path, such as `track/<id>`, `album/<id>`, or `playlist/<id>`.

```html
<div
  data-service="Spotify"
  data-id="track/4cOdK2wGLETKBW3PvgPWqT"
  data-widget
  style="width: 100%; height: 152px;"
></div>
```

#### SoundCloud

`data-id` is the URL-encoded SoundCloud API track URL.

```html
<div
  data-service="SoundCloud"
  data-id="https%3A//api.soundcloud.com/tracks/293"
  data-widget
  style="width: 100%; height: 166px;"
></div>
```

#### Twitch

`data-id` is a Twitch embed parameter such as `video=<id>` or `channel=<name>`.

```html
<div data-service="Twitch" data-id="video=992175865" data-autoscale></div>
```
