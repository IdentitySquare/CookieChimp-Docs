All eight 1.0.0 packages were published on npm on 17 October 2026. Standard SDK
installation commands work with that version.

Version 1.1.0 is the next coordinated release candidate. It adds the platform
JSON banner, category/vendor preferences and the variation playground, and fixes
consent restoration across regulations and consent UI locale isolation. The
`@cookiechimp/react/platform` and `@cookiechimp/react/platform.css` entries require
1.1.0 and are absent from 1.0.0. Use the workspace examples until the new version
is published.

Publication of 1.1.0 still requires live backend verification, review and approval
of that exact version. It is not released by publishing these documentation pages.

## Documentation

The Consent SDK guides live with the existing CookieChimp documentation on
Mintlify. The SDK repository keeps the source guides and runnable examples;
Mintlify provides navigation, search, Markdown views and AI documentation indexes.

## Connected mode

Local mode needs no account. Connected mode requires the shared platform config
and consent-ingestion endpoints to be deployed and tested with the project's
account. Cached or in-code config is a fallback; it does not prove consent records
were delivered. Verify connected delivery before using it in production.

## Optional IAB integrations

Production TCF requires a valid registered CMP ID, a current vendor list and IAB
validation. Applications supply the GVL and the authoritative feature decision.
The SDK does not provide a GVL CDN or enforce connected Pro entitlements.
See the [reference](/sdk/reference) for GPP coverage and TCF limitations.

## Translations

Banner and TCF interface labels are available in 33 editorially reviewed locales,
including right-to-left Arabic and Hebrew. See [translations](/sdk/translations).

## Publication

The eight packages are released together. Publication is a separate approval step
with package, fresh-consumer and provenance verification. Contributor procedures
are in the SDK repository's [release guide](https://github.com/cookiechimp/cookiechimp-sdk/blob/main/docs/release.md).
