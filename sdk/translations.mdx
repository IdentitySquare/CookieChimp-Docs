---
title: "Translations"
description: "Per-locale banner messages and opt-in TCF labels."
---

`@cookiechimp/translations` ships banner and preferences messages for 33
locales. Each locale is its own entry, so you only bundle what you import.

```tsx
import { ConsentProvider } from "@cookiechimp/react";
import de from "@cookiechimp/translations/de";

<ConsentProvider config={config} translations={de} language="de">
  ...
</ConsentProvider>;
```

In Next.js, pass `languages` and a `translations` resolver to
`CookieChimpProvider`. The server negotiates the language from
`Accept-Language`:

```tsx
import { CookieChimpProvider } from "@cookiechimp/nextjs/server";
import de from "@cookiechimp/translations/de";
import en from "@cookiechimp/translations/en";

const messages = { en, de };

<CookieChimpProvider
  config={config}
  languages={{ available: ["en", "de"], fallback: "en" }}
  translations={(locale) => messages[locale as keyof typeof messages]}
>
  {children}
</CookieChimpProvider>;
```

Locales: en, de, fr, es, it, nl, pt, pt-BR, pl, sv, da, fi, no, cs, sk, hu,
ro, bg, el, hr, sl, et, lv, lt, ga, mt, tr, ja, zh, ko, ar, he and uk. `ar` and
`he` are right to left (`rtlLocales`). `localeMeta` records editorial review
status for all 33 locales. `translationReview` from
`@cookiechimp/translations/meta` records the review method and date.

## Platform JSON content

The [platform UI](/sdk/platform-ui) uses the banner and nested category/vendor
`translations` from your existing JSON. Pass `locale` explicitly or use configured
browser/document hints. Region suffixes such as `fr-CA` select configured base
language `fr`. The selected banner language and RTL settings apply to the UI.
Translate the consent-ID label through `CookiePreferences`
`consentIdLabel`; it defaults to “Your consent ID”.

## TCF labels

The IAB TCF vendor list has its own labels in opt-in entries, so the banner
bundles above do not grow:

```tsx
import { TcfVendorList } from "@cookiechimp/react/tcf";
import de from "@cookiechimp/translations/tcf/de";

<TcfVendorList controller={tcf} labels={de} />;
```

All 33 TCF label sets have completed editorial review (`tcfReviewedLocales`
from `@cookiechimp/translations/tcf`). Numeric duration labels preserve the
`{days}` placeholder and use wording that works for singular and plural values.
Purpose, feature and vendor names come from the GVL; supply it in the same
language as the interface.
